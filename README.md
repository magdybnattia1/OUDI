# OUDI

تطبيق للتحكم الصوتي في أجهزة التلفزيون الذكية التي تعمل بنظام Android TV، مع التركيز على دعم الرسيفر الداخلي.

## الهدف
- استقبال الأوامر الصوتية من المستخدم.
- تحويل الكلام إلى أوامر واضحة.
- تنفيذ الأوامر المدعومة على التلفزيون بطريقة آمنة ومتوافقة مع صلاحيات Android TV.

## خطة العمل الأولية
1. تحديد إصدار Android TV والأجهزة المستهدفة.
2. بناء واجهة عربية بسيطة باسم OUDI.
3. إضافة استقبال الأوامر الصوتية والتعرف على الكلام.
4. ربط الأوامر بوظائف التلفزيون المتاحة عبر واجهات Android الرسمية.
5. اختبار التطبيق على جهاز فعلي قبل إصدار APK.

## ملاحظات
- المشروع في مرحلة التأسيس.
- دعم الرسيفر الداخلي هو النطاق الحالي؛ لا نفترض دعم الرسيفرات الخارجية.
- ستُحدد تفاصيل الأوامر والأجهزة المستهدفة أثناء التطوير.
